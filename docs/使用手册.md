# 使用手册

本文面向使用者，介绍从导入笔记到带引用问答的完整操作流程。安装、模型配置和故障处理见：

- [配置与模型](配置与模型.md)
- [架构与开发](架构与开发.md)
- [故障排查](故障排查.md)

## 1. 启动前检查

应用启动后，先看左下角的状态按钮：

| 显示 | 含义 |
| --- | --- |
| 模型已就绪 | 对话模型和嵌入模型都可用，可以导入和提问 |
| 部分模型未就绪 | 只有一侧可用；导入或问答会失败，悬停可看具体原因 |
| 待配置模型 | 通常是没有填写 API Key，或 LM Studio 的模型名仍为空 |
| 模型未就绪 | 网络、地址、余额或模型名有问题 |

点击状态按钮会重新检查。也可以打开「设置」→「测试连接」，这里会把对话侧和嵌入侧的结果分开显示。

> 导入文档必须用到嵌入模型；对话必须用到对话模型。任何一侧未就绪都不适合开始使用。

## 2. 界面概览

窗口分为左右两栏：

- **左侧栏**：导入入口、知识库文档列表、重建提示、模型状态、设置。
- **右侧聊天区**：问答消息、流式回答、引用来源卡片、输入框。

支持的格式：

```text
txt  md  markdown  docx  xlsx  xls  csv  pdf  pptx
png  jpg  jpeg  webp  bmp  tif  tiff
```

## 3. 导入笔记

有三种方式：

1. 点击「导入文件」，一次选择多个文件。
2. 点击「导入文件夹」，选择一个目录，递归导入其中所有支持的文件。
3. 把文件或文件夹直接拖进窗口。

文件夹导入的规则：

- 递归扫描子目录，最多 8 层。
- 忽略以 `.` 开头的隐藏文件和隐藏目录。
- 单次最多收集 5000 个文件。
- 只处理支持的扩展名，其余文件会被跳过。
- 不会跳过 `node_modules` 等普通目录；如果选择代码仓库，建议只选笔记子目录。
- 当前是一次性导入，不会监听文件夹后续变化；新增文件需要再次导入。
- 文件夹导入会保留相对目录，在左侧知识库中按「所选文件夹 → 子目录」分组展示。
- 单独导入的文件直接放在知识库根级；旧版本导入的文档没有目录信息，也会显示在根级，重新导入文件夹即可获得层级。

导入时会把原文件复制一份到知识库，之后即使移动或删除原文件，应用内仍可检索和查看解析结果。删除知识库条目不会影响原文件。

> 同一个文件重复导入会生成重复条目，目前没有按内容去重；需要时手动删除多余条目。

## 4. 索引状态

每个文档在列表中有四种状态：

| 状态 | 显示 | 说明 |
| --- | --- | --- |
| 排队 / 索引中 | 「解析索引中…」 | 正在解析、切块、生成向量 |
| 就绪 | 「类型 · 片段数 · 日期」 | 可以检索，点击可查看解析全文 |
| 失败 | 「索引失败」+ 红色原因 | 悬停或查看错误行；点开可看失败原因和已保存的原文，再重试索引 |
| 已中断 | 「上次索引未完成」 | 应用在索引过程中退出，重启后转为失败状态，重试即可 |

只有「就绪」的文档参与检索。索引任务按队列串行执行，一次导入多个文件时会逐个处理。

常见失败原因：

- 嵌入模型不可用、API Key 错误、余额不足。
- PDF 是扫描件，没有可提取文字。
- 图片没有 OCR 语言数据，或没有配置视觉模型。
- 原文件在导入过程中被移动或删除。

## 5. 提问与引用

在底部输入问题，按 `Enter` 发送，`Shift + Enter` 换行。

回答流程：

1. 问题先被向量化。
2. 同时进行向量召回和 BM25 关键词召回，融合排序。
3. 按上下文预算取前若干条片段，发送给对话模型。
4. 回答流式显示，句末带 `[n]` 引用编号。
5. 回答下方出现引用卡片，只显示 `[编号]` 和文档名；悬停可看标题路径 / 页码，点击打开原文。

点击引用卡片或左侧文档可以打开预览：TXT 和 Markdown 直接展示库内保存的原文，Markdown 默认渲染排版，可在右上角切换「预览 / 原文」；Word 展示排版与表格，Excel 按工作表展示表格，PDF 显示原页，PPT 按幻灯片展示文字、图片与表格，图片直接显示。预览弹窗里可用系统程序打开原文件，或对该文档重建索引。

生成过程中可以点击输入框右侧的停止按钮。已经生成的部分会保留，并标注「已停止生成」。

需要注意：

- 对话是多轮显示，但每次提问都是独立的单轮检索，不会携带上一次对话作为上下文。
- 对话记录只保存在当前窗口内，关闭应用后清空。
- 资料不足时，助手应回答「笔记中没有找到相关内容」，而不是编造。
- 检索接口支持按文档范围过滤，但当前界面还没有提供「只查某几篇」的入口。

## 6. 文件夹与文档管理

左侧文档列表：

- 点击文档 → 查看解析全文；索引失败的文档也能打开，会显示失败原因，纯文本 / Markdown 直接展示库内原文。
- 通过「导入文件夹」加入的文档按目录树分组，点击目录行可展开 / 收起；目录默认折叠，只展开你主动点击的层级。悬停目录行会显示完整相对路径。
- 顶部「知识库」右侧的文件夹按钮可新建根目录；悬停目录行会出现「新建子目录 / 重命名 / 删除」按钮。删除目录只删分类，里面的文档和子目录会上移到上一级，不会丢失。
- 文档行左侧的复选框可以多选，列表顶部的「全选」会选中所有文档；选好后点「批量移动」，在弹窗里统一选择目标目录。单选文档时也可以悬停点击移动按钮，或直接把文档拖到目录行；拖到「拖到这里移到根目录」条可移回根级。
- 目录只是知识库内的分类，不会改动磁盘上的原始文件；所有目录中的文档仍会一起参与检索。
- 悬停文档 → 右侧出现删除按钮；删除前会确认。
- 索引失败的文档 → 出现重试图标，弹窗内也有「重试索引」。
- 顶部「知识库」右侧显示「就绪数 / 总数」。

文档弹窗底部：

- **重建索引 / 重试索引**：重新解析、切块、向量化该文档；失败文档显示为「重试索引」，完成后弹窗自动刷新。
- **打开原文件**：用系统默认程序打开库内保存的副本。
- **关闭**：也可以按 `Esc` 或点击遮罩关闭。

## 7. 何时需要重建索引

以下变更会让旧向量和新查询不在同一个向量空间，必须重建索引：

- 更换嵌入提供方（百炼 / LM Studio 兼容服务 / Ollama）。
- 更换嵌入模型（如 `text-embedding-v4` → `bge-m3`）。
- 更换百炼的向量维度（如 1024 → 768）。
- 更换 LM Studio / OpenAI 兼容服务的地址，或换成维度不同的嵌入模型。

出现这些变更时，左侧会出现「嵌入模型已变更」提示，点击「重建」即可。重建期间旧文档仍然可以按关键词检索，但向量部分要等重建完成。

以下变更不强制重建，但只对之后导入或重建的文档生效：

- 分块大小、分块重叠。
- 引用片段数、温度、上下文字符上限。

## 8. 设置入口

左下角「设置」可以配置：

- 界面外观：浅色 / 深色主题；切换时立即预览，保存后下次启动沿用。
- DeepSeek / LM Studio / Ollama 对话模型与地址。
- 百炼 / LM Studio / Ollama 嵌入模型、Key、地址、维度。
- 可选的重排序（qwen3-rerank）：开启后，检索到的候选片段会先由百炼重新打分再交给对话模型。
- LM Studio 或任意 OpenAI 兼容服务的地址与可选 Key（对话和嵌入共用）。
- 检索参数、分块参数、上下文预算。
- 本地 Ollama 地址、视觉模型、OCR 语言。

每个字段的含义、默认值和取值范围见[配置与模型](配置与模型.md)。

设置只写入本机 `%APPDATA%\JydNote\settings.json`。云端模式下，问题、命中的片段、文档名和标题路径会发送给对应的模型服务；未命中的文档不会发送。API Key 在该文件中是明文。

## 9. 数据与迁移

Windows 下数据位置：

```text
%APPDATA%\JydNote\
├─ settings.json
├─ library\
│  ├─ index.json
│  ├─ folders.json
│  └─ docs\<id>\
│     ├─ source.*
│     ├─ doc.json
│     └─ vectors.bin
└─ ocr-cache\
```

- 备份或迁移：退出应用后复制整个 `%APPDATA%\JydNote` 目录。
- 清空知识库：删除 `library` 目录（会同时删除库内副本）。
- 删除单条：使用界面中的删除按钮，只删除库内副本。
- 索引损坏：删除该文档后重新导入，或在文档弹窗中重建索引。

## 10. 使用建议

- 导入前把不相关内容排除掉，避免选择包含大量代码或附件的目录。
- 长文档不需要手动切分，应用会按标题、段落和页码切块。
- 问题尽量包含笔记中的专有名词；BM25 与向量检索互补，具体问法通常更容易命中。
- 如果回答引用不相关，先检查文档片段质量（扫描件、表格表头、图片 OCR）。
- 个人笔记很多时，优先用文件夹按主题分组导入，便于以后整体清理。

## 11. 已知限制

- 不支持 `.doc`、`.ppt`、加密文档；`.pptx` 只预览解析出的文字、图片与表格，动画和主题字体可能与 PowerPoint 有差异。
- 扫描版 PDF 不会自动渲染页面做 OCR；可以把页面截图当图片导入。
- 图片只保留 OCR 文字或视觉模型描述，不保留版面坐标。
- Excel 只索引单元格文本值，不保留公式、样式和图表。
- 文件夹只做一次性导入，不监听变化。
- 知识库文件和 API Key 都未加密，敏感数据请配合磁盘加密使用。
